# Security policy

CS2 Mod Verifier is a security tool, so problems in it matter. Thank you for reporting them.

## Report a vulnerability

Please report security problems privately through GitHub: on this repository's **Security** tab, choose **Report a vulnerability**. Do not open a public issue for them.

Useful to include: what you found, the version (shown in the exe's file properties), and how to reproduce it.

Examples of what counts as a security problem:
- a way to make the tool load or run mod code;
- a mod file that crashes or hangs the tool, or makes it skip a check;
- a way to hide code from the source comparison or the risk checks;
- network access to anything other than GitHub.

## Supported versions

Only the latest release is supported. Fixes are released as a new version.

## Scope

This policy covers this tool. To report a harmful **mod**, use the mod's page on Paradox Mods.
