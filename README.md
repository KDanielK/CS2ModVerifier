# CS2 Mod Verifier

A small Windows tray app that checks the Cities: Skylines II code mods installed on your PC. It compares each mod with its published source code, checks its files against what Paradox Mods delivered, and points out risky code, in plain language. It reads mod files as data only and never runs mod code.

Why: code mods run inside the game with your full Windows user rights, and nothing ties a mod downloaded from Paradox Mods to the source code on GitHub. In October 2024 a compromised account uploaded a version of the Traffic mod with a hidden data stealer; that version was never on GitHub.

## What it checks

1. **Source comparison.** Takes the GitHub link from the mod's Paradox Mods page (as stored by the game on your PC), finds the commit the mod was built from, and compares the types and method signatures in the mod's DLL with that source. Reports every type or method in the DLL that is not in the source. It also traces each risky call (starting programs, internet access, loading code at runtime, native Windows functions, the registry) to the method that makes it, and shows the file and line in the source where that call appears, or reports it when the source does not contain it. Code generated by the C# compiler and the game's build tools is listed separately rather than hidden. A mod without a GitHub link is reported as having no source to compare.
2. **File integrity.** Compares the SHA-256 hash of every file with the file list Paradox Mods delivered with the mod. Reports files that were changed, removed or added after download.
3. **Unexpected files.** Identifies each file by its content, not its name. Reports programs, scripts, native libraries other than the standard ones that every code mod ships, and files disguised with a different extension. Also lists extra .NET libraries bundled with a mod, and recognises official builds of Harmony by comparing their SHA-256 hash with Harmony's GitHub releases. The tool ships with a list of known builds and looks up newer versions in Harmony's releases when a mod uses one. A file named like Harmony that matches no official build is reported.
4. **Code references.** Reads each mod DLL as data, without loading or running it, and lists the system features its code refers to: internet access, starting programs, loading other code at runtime, native Windows functions, the Windows registry, files and folders, user folders such as AppData, and suspicious text such as web addresses.

The app lists each code mod with a badge for its most serious open finding. Expand a mod to see its findings, hover over anything for an explanation, and ignore findings you have looked into. It watches your mod folders and checks new and updated mods automatically, with a Windows notification.

## Disclaimer

CS2 Mod Verifier is an aid, not a guarantee of safety.

- **No findings does not mean a mod is safe.** The tool only finds what the checks above look for. Code can be written to avoid them.
- **A finding does not mean a mod is harmful.** It is a reason to take a closer look. Many legitimate mods use these features, for example file access to save their settings.
- **Matching the source does not prove the source is harmless.** The source comparison checks that the DLL's types, method signatures and risky calls appear in the source. A call found in the source can be read there, but that does not mean anyone has reviewed it. The rest of the code inside each method is not compared.
- **Matching the Paradox file list does not prove the upload is genuine.** It shows the files are the ones Paradox delivered. If an author's account is compromised, Paradox delivers the attacker's files.
- **Native code is not inspected.** Native libraries are only identified by name and hash.
- Only install mods from sources you trust. You are responsible for what you install.

## Install

Requires Windows 10 or 11 (64-bit). Nothing else needs to be installed.

1. Download `CS2ModVerifier-vX.Y.Z-win-x64.zip` from [Releases](https://github.com/KDanielK/CS2ModVerifier/releases).
2. Check the download (see below), extract it, and run `CS2ModVerifier.exe`.
3. Read and accept the explanation on first start. The app opens its window and checks your mods; afterwards it runs in the tray (the shield icon).
4. Optional: right-click the tray icon and turn on **Start with Windows**. It is off by default. It adds an entry for your Windows user only (no admin rights needed).

The exe is not code-signed, so Windows SmartScreen may warn that it is from an unknown publisher. Check the download first, then choose "More info" and "Run anyway".

**What it stores:** settings, ignored findings, cached results and a log in `%LOCALAPPDATA%\CS2ModVerifier`. To remove the app, turn off "Start with Windows" if you turned it on, exit the app from the tray menu, and delete the exe and that folder.

**Network use:** it only contacts GitHub: `api.github.com` to read the public repositories linked from mod pages and the official Harmony releases, and GitHub's own download hosts that the API redirects to. It sends no information about you, your PC or your mods; GitHub sees an ordinary web request (including your IP address), as with any website. Repositories are never searched for: only the link on a mod's Paradox Mods page is used. GitHub allows 60 requests per hour without an account; a mod usually needs one or none, and results are remembered. If the limit is reached, the remaining mods show "Waiting for GitHub" and are compared automatically once it resets.

Want to help test? See [TESTING.md](TESTING.md).

## Check that a download is genuine

Releases are built only by the [release workflow](.github/workflows/release.yml) in GitHub Actions, never on a personal PC. Each release has a build provenance attestation, which shows the file was built by that workflow from this repository at the tagged commit. With the [GitHub CLI](https://cli.github.com/):

```
gh attestation verify CS2ModVerifier.exe --repo KDanielK/CS2ModVerifier
```

You can also compare the SHA-256 hash with `SHA256SUMS.txt` from the release:

```
Get-FileHash CS2ModVerifier.exe
```

## How this tool's own code is checked

- **CI:** every push and pull request is built and tested on Windows ([workflow](.github/workflows/ci.yml)).
- **CodeQL** code scanning on every push and pull request.
- **Secret scanning** with push protection.
- **Dependabot** alerts, security updates and weekly version updates for NuGet packages and GitHub Actions.
- **Release provenance:** see above. GitHub Actions used by the workflows are pinned to exact commits.
- **Branch protection:** changes to `main` go through a pull request with a passing CI build.

A clean scan means these checks found no problems, not that there are none. Please report anything you find (see below).

## Build from source

Requires the [.NET 10 SDK](https://dotnet.microsoft.com/download) on Windows.

```
git clone https://github.com/KDanielK/CS2ModVerifier.git
cd CS2ModVerifier
dotnet test
dotnet run --project src/CS2ModVerifier.App
```

There is also a console tool: `dotnet run --project src/CS2ModVerifier.Cli -- verify` checks all installed mods, `scan` runs only the local checks, and `compare --dll <path> --repo <owner/name> --ref <tag-or-commit>` compares one DLL with a repository.

To refresh the built-in list of official Harmony builds, run `tools/Update-KnownLibraries.ps1` (needs the GitHub CLI).

## Report a problem

- **Bugs, wrong or unclear findings, ideas:** open an [issue](https://github.com/KDanielK/CS2ModVerifier/issues/new/choose).
- **A security problem in this tool:** please report it privately, see [SECURITY.md](SECURITY.md).
- **A harmful mod:** report it to Paradox through the mod's page on Paradox Mods.

## Built with

- [.NET 10](https://github.com/dotnet/runtime) and Windows Forms; DLLs are read with `System.Reflection.Metadata`, part of .NET.
- [Roslyn](https://github.com/dotnet/roslyn) (`Microsoft.CodeAnalysis.CSharp`) to parse C# source for the source comparison. This is the only third-party package in the app.
- Harmony's official release hashes, from [pardeike/Harmony](https://github.com/pardeike/Harmony), to recognise official builds. No Harmony code is included.
